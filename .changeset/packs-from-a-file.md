Owners and Admins can install a Pack from a file on the new Packs page (Workspace → Packs): Ziffr checks the whole file, shows every item drawn with sample data and any words aimed at AI assistants, and installs its Metric Catalog entries, templates, View Designs and Themes in one step, without making any Metric. Members see which Packs are installed and what each added.
