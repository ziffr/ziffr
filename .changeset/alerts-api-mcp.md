Programs and assistants can now set your own Alerts: Access Keys have a new scope, Manage alerts, and the API, the SDK and the MCP Server get Alert endpoints and tools (`list_alerts`, `create_alert`, `update_alert`, `delete_alert`) and an "Alert me when…" Starter. A key sets Alerts only for the person who made it, on Metrics they see, within the same limits as the app.
