Programs and assistants can now work with Questions and Tasks: Access Keys have three new scopes, Read questions and tasks, Answer questions and tasks and Approve values, and the API, the SDK and the MCP Server get endpoints and tools to list yours, reply in a Thread, close or reopen, mark a Task done, and confirm or correct your own value in a Self-check. Approving a value or sending it back works only with a program's Access Key that you tick "Approve values" on yourself: assistants are not offered it and the MCP Server has no tool for it, and, as in the app, nobody approves their own value.
