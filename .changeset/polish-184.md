Polish from the 0.10.0 release check. Chart axes step by round numbers and write every label the same way: "$0, $5k, $10k, $15k" instead of a mix of full and shortened numbers, and a chart of one value starts at 0. Typing "$", "£" or a currency code as a Metric's unit puts it before the number, and "€" or "%" after, until you pick a side yourself. The Breakdown hint on a Metric's page writes its example in the Workspace's Number Style. The deck name keeps its room on narrower screens. A View Design or Analysis Recipe with an unknown field names it once. The Audit Log says "from the default" for a Number Style or Answer Languages change in a Workspace without a country. The demo's deck "Board update" now has five slides of the demo's Metrics, so trying Present or the PowerPoint export shows something. Every negative number shown on screen and in decks now has the same minus sign "−", values and changes alike, where values used to have "-" and changes "−", sometimes in one row; CSV files keep a plain "-" so spreadsheets read them, and Ziffr still reads either sign you type.
