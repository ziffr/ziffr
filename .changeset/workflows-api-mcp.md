Programs and assistants can now build Workflows: Access Keys have a new scope, Build workflows, and the API, the SDK and the MCP Server get endpoints and tools to make, read, change and delete your own Workflows and their steps, through the same checks as the Workflow editor. Choosing who approves a value, and who a Tell step tells, needs a second scope, Name who approves and who is told, which only a program's Access Key can hold: assistants are not offered it and cannot change a Workflow's Approvers.
