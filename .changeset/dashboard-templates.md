Dashboard Templates: start a new dashboard from a template, such as "One metric in depth", and pick each Metric once, even when several widgets show it. Save any dashboard you may change as a template for your team with "Save as template" in its ⋯ menu.

Developers: two new Access Key scopes, "Read dashboards" and "Build dashboards", let programs and the MCP server list and read dashboards, make one from a Dashboard Template, add and change widgets, and write a dashboard's introduction and Findings, as the key's creator. A key never shares, deletes or publishes, and every change it makes is in the history under its name. See `/api/v1/dashboards` and `/api/v1/templates` in the API reference.
