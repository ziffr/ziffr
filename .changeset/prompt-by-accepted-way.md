A request for a value now goes only by a way the Metric accepts answers by, never with a form link for a Metric that refuses the Web form. If your usual way is not accepted or does not reach you, it goes by the first of Slack, Telegram and email that does; if none does, it waits in the Outbox as "Not sent" and the Metric's owner is told once. The Metric page shows where each submitter's next request goes and why, Ask me now says where it sent, and Values arrive by points to Who gets what, where.
