Installation Admins can read how this Ziffr is used: daily counts of Workspaces, people, Metrics, values, calls and views, on the Installation settings page and, with a Usage Key, from `GET /api/v1/installation/usage`. Never a name, a person or a value; fewer than 3 Workspaces show totals only. Self-hosters: the Docker clock now also calls the daily `usage-rollup` job at 04:40 UTC.
