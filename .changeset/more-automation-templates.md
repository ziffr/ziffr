Four more importable n8n workflows pair Ziffr with the tools people already use: Slack (Tasks and Alerts in a channel, a tick or a reply in a message's thread back to Ziffr), Asana, Todoist and Microsoft Planner (Tasks given in Ziffr appear there and are ticked off when done; ticking one marks the Task done). Each is tried against recorded messages in tests, not yet against the real service.
