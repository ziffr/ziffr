A Pack's Metric Catalog entries may carry up to 5 Tags. A Metric made from such an entry, by Set up from this Pack or from New metric, gets them; if a Tag limit is reached the Metric is still made and Ziffr says which Tags stayed off. Export as Pack carries the Tags of the Metrics you pick, only those you can see on them, and you can leave them out. Developers: `npx @ziffr/pack check` checks `tags` with the same rules as the app.
