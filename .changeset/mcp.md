Developers: `@ziffr/mcp`, an MIT-licensed MCP server, lets an assistant such as Claude Desktop or Claude Code read your Metrics and submit values with an Access Key: run `npx @ziffr/mcp` with `ZIFFR_URL` and `ZIFFR_ACCESS_KEY`. It offers `list_metrics`, `get_metric`, `submit_value` and `list_people`, and every visible Metric as a resource. It sees only what the key's creator sees. See `packages/mcp/README.md`.
