# Code of Conduct

Ziffr follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good intent, criticise ideas and not people, and help newcomers.

Report unacceptable behaviour privately to the maintainers through the private report on the Security tab ("Report a vulnerability"; say that it is about conduct), or to GitHub with "Report content". Reports are handled confidentially.
