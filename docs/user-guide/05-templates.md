# Templates: starting points

You rarely have to start from an empty page in Ziffr. Several kinds of starting points help you describe Metrics, draw them and build dashboards. All of them are copied when you use them: changing the starting point later does not change what you already made.

## The Metric Catalog

The **Metric Catalog** is a library of ready-made Metric descriptions, grouped by area: Finance, Sales, Customers, Marketing, Product, Operations, Support and People. Each one already says what the number means, its unit, how often it is counted, whether higher or lower is better, and a sensible target range.

Picking "Monthly recurring revenue" from the catalog copies its description into a new Metric of your own. From then on it is yours: change anything you like, there is no link back to the catalog. Ziffr also uses your **Workspace Profile** (your industry, who you sell to, your size) to suggest the Metrics that fit your kind of business.

## Widget Templates

A **Widget Template** is a starting point for one Widget: a way of drawing a number, with its settings, and an open place for the Metric. Ziffr ships these:

| Group | Widget Template | Shows |
| --- | --- | --- |
| Numbers | Number + sparkline | The latest value, its change and a small trend |
| | Line chart | The trend with its target band and, if you like, a forecast |
| | Bars per period | One bar per period, coloured by target |
| | Gauge vs. target | Where the latest value sits against the target |
| | History table | The last values as a list |
| | Stacked bars over time | How a Breakdown changes period by period: one stacked bar each. Offered for a Metric that has a Breakdown |
| | Pareto | A Breakdown's rows from largest to smallest, with the running share that shows which few make most of it |
| | Bump chart | How the order of a Breakdown's rows changes from period to period (offered for a Metric that has a Breakdown) |
| | Heatmap | A grid of periods shaded by value: weekdays, seasons and quiet spells at a glance |
| Analyses | Forecast | The trend projected a few periods ahead |
| | Correlation | Whether two Metrics move together |
| | Correlation matrix | Every pair of several Metrics at once |
| | Drivers | Which Metrics move most with this one |
| | Progress against target | Each Metric's latest value against its target, one compact bar each |
| | Scoreboard | Several Metrics in one table: latest value, change, status and a small trend |
| | Slope chart | Two moments side by side: who rose and who fell between them |
| | Running total against target | The year so far, added up, against the target and last year |
| Findings | Ranked bars | A Breakdown, largest first, one row highlighted |
| | Part of the whole | How a Breakdown divides the total |
| | 7 in 10 | The largest share as ten figures |
| | Annotated line | The trend with callouts at moments that matter |
| | Composed | A frame around one or more panels: period bars, bridges, small multiples |
| Layout | Free layout | Widgets, text, arrows and shapes placed freely, like on a slide |

Anyone can save a Widget they made, with its words and annotations, as a team Widget Template. Only the person who saved it can change it; everyone else can use it.

## Dashboard Templates

A **Dashboard Template** is a starting point for a whole dashboard: its Widgets, their layout and their words, with the Metrics left open. Ziffr ships eight:

- **Overview**: four numbers at a glance, the first two also as trends against their targets.
- **One metric in depth**: one Metric from every side: its latest value, where it sits against the target, its trend, its periods, its history and a forecast.
- **Two metrics side by side**: two Metrics next to each other, and whether they move together.
- **Scorecard**: six Metrics as gauges against their targets: what is on track and what is not, at a glance.
- **Trends board**: four trends side by side against their targets, and the first one forecast. For a weekly or monthly review.
- **Target tracker**: three Metrics, each as its latest value and its periods coloured by whether they were on target, so you see how often it was on track.
- **Weekly check-in**: four numbers with their change since the last period, and the last values of the first two: a glance to start the week.
- **Board pack**: a written Finding on the first Metric (its change on last year, in period bars) and an annotated trend for the second, with the numbers behind them.

When you have built a dashboard the team likes, such as "Monthly board pack", you can save it as a team Dashboard Template, so the next one starts from it. You can do this when you may change the dashboard and see every Metric on it.

In the demo, where visitors may change it, you may make a dashboard from a template and save a widget or a dashboard as a template of your own, with a short name and plain words. What you save is seen by every visitor and gone when the demo starts fresh.

## Deck Templates and Workflow Templates

A **Deck Template** is a starting point for a whole deck: its slides with their Widgets, words and boxes, the Metrics left open as Slots. Save a deck as one with **Save as Deck Template…** in the deck editor, and start a deck from one on the Decks page (Decks and Themes). In the demo, where visitors may change it, you may save a deck as a Deck Template, save a slide as a layout and start a deck from a Deck Template, with plain words and no pictures; Workflow Templates stay off.

A **Workflow Template** is a starting point for a Workflow: its Due Date, steps and reminders, with the people left open. Its **checklist items** come along with their words, day and Due Date, but never the people they go to, the Group that reads them or the person who ticks them off: you pick those in the editor after you start a Workflow from it. Save a Workflow as one with **Save as template…**, and start one with **New from a template** on the Workflows page (Workflows and approvals).

## Slots and Placeholders

A template never contains your numbers. Instead it has:

- **Slots**: the open places that you fill with a Metric when you use the template. One Slot can fill several Widgets, so choosing "Revenue" once puts it into every Widget that needs it.
- **Placeholders**: words in a template's text that are filled in from the data, such as the Metric's name, the latest period or the change against last year. A headline like "Revenue rose 12% against last year" then stays correct for whatever Metric you choose.

## Previews

Before you place a template, Ziffr draws a small **Preview**. Because a template has no Metrics of its own, its Preview uses **Sample Data**: made-up numbers that are the same for everyone and never come from your Workspace. A saved Widget's or a Metric's Preview shows your own data.

## Recipes

A **Recipe** is a ready-made analysis that runs with one click on the Analysis Canvas, such as "What drives Cost?". It picks the right method and settings for you.

## Themes

A **Theme** is not a starting point, but it decides how everything with numbers looks: colours, fonts, how cards are drawn, and what every slide shows, such as your logo, a footer and slide numbers. The team has one default Theme; a dashboard or deck can use another. Owners and Admins change Themes.
